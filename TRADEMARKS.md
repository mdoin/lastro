# Política de marca do Lastro

O **código** do Lastro é software livre sob a [GNU AGPL-3.0-or-later](LICENSE). O **nome** "Lastro" e os
**elementos de marca** não fazem parte dessa licença: eles identificam o projeto oficial, para que ninguém confunda uma
versão modificada (que pode tratar dados financeiros de outro jeito) com o projeto original.

## Elementos de marca
- O nome "Lastro" usado para identificar este software.
- Os arquivos em `docs/brand/` (símbolo, assinaturas, ícones) e os ícones do aplicativo em `frontend/public/`
  (`favicon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`).
- O símbolo desenhado pelo componente `BrandMark` (`frontend/src/components/Icon.tsx`).
- Os personagens dos mascotes dos agentes (`frontend/src/components/mascots.ts`) quando usados como identidade visual
  de outro produto. O código do arquivo segue a AGPL; o que esta política restringe é usar os personagens para
  apresentar outro software como se fosse o Lastro.

Os arquivos de `docs/brand/` e os ícones de `frontend/public/` listados acima são © os autores do Lastro, todos os
direitos reservados, exceto pelas permissões abaixo. Para o símbolo e os mascotes que existem como código, a AGPL
vale para o código; esta política vale para o uso deles como marca.

## O que você pode fazer sem pedir
- Usar, instalar e hospedar o Lastro **sem modificações** com o nome e a marca, inclusive para uso próprio, da sua
  família ou da sua organização.
- Modificar o Lastro para uso próprio na sua instalação, mantendo a marca, desde que não distribua nem ofereça essa
  versão a terceiros como "Lastro".
- Dizer, em texto, que o seu projeto "é baseado no Lastro", "é compatível com o Lastro" ou "usa o Lastro".
- Usar o nome e o logotipo em artigos, aulas, vídeos e notícias sobre o projeto, sem alterar o logotipo.

## O que exige outro nome e outros ícones
- Distribuir uma versão modificada, ou oferecê-la pela rede a outras pessoas (o que a AGPL permite, com publicação
  do código): troque o nome e os elementos de marca listados acima.
- Usar "Lastro" no nome de outro produto, serviço, empresa ou domínio de forma que sugira ser o projeto oficial ou ter
  apoio dele.
- Oferecer o Lastro como serviço hospedado para terceiros usando o nome, sem autorização por escrito.

## Dúvidas e pedidos
Abra uma issue marcada como "marca" ou use o canal privado de [SECURITY.md](SECURITY.md) quando envolver dados
pessoais. Esta política pode evoluir; a versão no repositório oficial é a que vale.
